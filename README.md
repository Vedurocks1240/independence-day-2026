# 🇮🇳 Independence Day 2026

A dark-themed glassmorphism website celebrating India's 80th Independence Day with a live countdown to 15 August 2026 at 12:00 IST.

## Features

- **Dark Glassmorphism UI** — Frosted glass card with backdrop blur
- **Terminal Matrix Background** — Canvas-animated Devanagari + binary rain in Indian flag colors
- **Live Countdown** — Accurate to 15 Aug 2026, 12:00 IST (UTC+5:30)
- **ASCII Art Title** — "INDEPENDENCE" in block letters
- **Animated Ashoka Chakra** — CSS spinning 24-spoke wheel
- **Rotating Quotes** — Freedom quotes from Indian leaders
- **Responsive** — Works on mobile and desktop

## Tech Stack

- Vite
- TypeScript
- Vanilla CSS (no frameworks)

## Deploy to Vercel

1. Push this repo to GitHub
2. Import on [vercel.com](https://vercel.com)
3. Framework: **Vite**
4. Build: `npm run build`
5. Output: `dist`

## Local Dev

```bash
npm install
npm run dev
```
